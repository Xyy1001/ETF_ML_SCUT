# ML-ETF Optimizer: 策量科技

## 项目概述
**ML-ETF Optimizer** 是一个融合前沿机器学习技术的动态投资组合优化系统，旨在解决个人投资者面临的三大核心痛点：
- **数据维度割裂**：整合基本面、情绪面与跨资产关联数据
- **策略响应迟滞**：通过事件驱动的强化学习实现毫秒级调仓
- **风险适配僵化**：基于元学习的个性化策略生成
> 📌 **核心创新**：首次将 **GNN风险图谱 + Transformer时序建模 + MAML元学习** 融合应用于ETF配置领域，实现"千人千策"的智能资产管理

## 技术架构
| 模块 | 技术方案 | 创新点 |
|------|----------|--------|
| **数据融合** | GNN + Transformer + LSTM/GRU双通道 | 量化300+因子与社交情绪的非线性关联 |
| **动态决策** | PPO算法 + 蒙特卡洛置信度阈值 | 50ms极速响应市场事件 |
| **个性适配** | MAML元学习 + 风险向量映射 | 支持[-10%,+15%]弹性回撤区间 |
| **轻量化部署** | 知识蒸馏 + 模型剪枝 | 模型体积压缩至传统方案的23% |
