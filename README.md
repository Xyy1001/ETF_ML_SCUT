### 🔹 模块D：投资决策与回测

**Markowitz优化流程**
```
输入: μ(预期收益向量) + Σ(协方差矩阵)
      │
      [求解KKT条件]
      │
  max w^T·μ - γ·w^T·Σ·w   (γ = 风险厌恶系数)
  s.t. Σw_i = 1, w_i ≥ 0
      │
输出: 最优权重向量w*
```

**回测引擎特性**
- ✅ 支持多股票组合回测
- ✅ 日级别调仓，实时权重更新
- ✅ 完整性能指标计算
- ✅ 可视化曲线输出(净值、回撤、收益)

**关键指标**
```
累计收益率 = (终端净值 - 1) × 100%
年化收益率 = (累计收益率)^(252/天数) - 1
年化波动率 = 日对数收益率标准差 × √252
夏普比率   = 年化收益率 / 年化波动率
最大回撤   = min((当前净值-峰值净值)/峰值净值)
```

**使用示例**
```python
python C-Backtest/backtest.py \
    --returns_dir "26个股票预测结果" \
    --risk_dir "results(risk)" \
    --actual_dir "回测数据1" \
    --gamma 1.0
```

### 环境配置
```bash

git clone <repository-url>

```
